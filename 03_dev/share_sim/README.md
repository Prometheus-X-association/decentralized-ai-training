# Simulated environment for `share`-based architecture

In this folder, one can find codes for simulating and testing the shares-based aggregation architecture.

## Preliminaries
1. Install `pytorch`.
2. Download [MNIST dataset](https://www.kaggle.com/datasets/hojjatk/mnist-dataset?resource=download). Unzip it and place in `02_data/mnist` folder.
3. Run all cells in [mnist_partitioner.ipynb](mnist_partitioner.ipynb) to distribute MNIST data among 10 fictive participants.
